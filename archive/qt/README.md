qt 是一个 SKILL
- 完整名称
  - Question Transformer，即问题变换器
- 目标
  - 将原始问题重组成新问题
- 有助于
  - 跳出问题本身框架，找到真正的问题

存在原因
- LLM 可能被问题误导
  - 问题本身可能包含
    - 概念混合
    - 隐含条件
    - 默认目标
    - 固定观察尺度
  - 若直接回答
    - 容易沿原有框架生成内容
    - 回答的质量强依赖于模型本身
    
设计要点
- 将目标刻意从 `SKILL.md` 中分离，这是为了避免模型硬凑答案
  - README 描述目标和设计
  - SKILL 仅含有指令和执行步骤等
- 让模型执行固定的方法和思考步骤，更广泛搜索到真正的答案
  - 这些体现在 SKILL 中
